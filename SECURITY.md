# Security policy

## Supported versions

Security fixes target the latest release. Until a stable release is available,
this is the latest nightly prerelease. Update before reporting a vulnerability
if it is safe to do so.

## Report a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/grendalaget/varde/security/advisories/new)
to report vulnerabilities privately. If that option is unavailable, email
[support@varde.games](mailto:support@varde.games).

Do not disclose vulnerabilities in public issues. Include the affected version,
platform, reproduction steps and potential impact. Remove passwords, tokens
and personal information from logs and attachments.
